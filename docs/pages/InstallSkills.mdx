<Title>Install the optional `specx` skill</Title>
<Subtitle>Add project-navigation help without making skill installation a prerequisite.</Subtitle>

Install the one skill for Codex when you want its navigation workflow:

```sh
npx skills add maksimzayats/specx --skill specx --agent codex -y
```

This does not install the Python package or mutate application code. Projects and CI should install
the `specx` package and run executable checks regardless of whether any agent skill is installed.

Inspect a checkout before installing:

```sh
git clone https://github.com/maksimzayats/specx.git
cd specx
npx skills add . --list --full-depth
```

Invoke it explicitly when useful:

```text
Use $specx to inspect this project, implement the order-status action, follow structured
architecture diagnostics, and run the full project check.
```

Run the install command again to update. Review skill changes because they affect future agent
navigation, even though executable checks remain authoritative.
