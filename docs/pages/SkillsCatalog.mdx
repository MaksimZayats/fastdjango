<Title>Optional `specx` skill</Title>
<Subtitle>One navigation aid; executable project checks remain the correctness contract.</Subtitle>

specx ships one optional `specx` skill. A project does not need the skill to be understandable or
enforceable: foundation types, `specx project`, `specx check`, diagnostic hints, generated project
guidance, and these public guides carry the contract.

The skill gives an agent a short navigation workflow:

- inspect `AGENTS.md`, `pyproject.toml`, `Makefile`, source, and tests;
- use existing project discovery and scaffold commands;
- run `specx check --output-format json`;
- follow diagnostic `hint` and `documentation_url` fields;
- consult the relevant public guide for design judgment;
- finish with the project's complete check command.

It does not contain alternate architecture recipes or replace rule documentation. Canonical source
lives under [`skills/specx/`](https://github.com/maksimzayats/specx/tree/main/skills/specx), and the
tracked `.agents/skills/` copy is generated by repository tooling.
