## `delivery.foundation-classes-live-under-delivery`

Place concrete delivery foundation subclasses under the top-level delivery package.

**Status:** Enabled by default.

### Why this exists

Controllers, delivery services, schemas, and lifecycles translate runtime protocols and therefore belong at the delivery edge.

### Failing example

```python
class OrderController(BaseController):
    pass  # core/orders/controllers/order.py
```

### Passing example

```python
class OrderController(BaseController):
    pass  # delivery/http/controllers/order.py
```

### Detection notes

Follows path-qualified project inheritance from controller, delivery-service, schema, and lifecycle
bases. Statically abstract or `Base...` extensions are exempt; a concrete class in a foundation path is not.
