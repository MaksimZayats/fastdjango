## `sqlalchemy.models-live-under-scope-infrastructure`

Place concrete SQLAlchemy models under their owning scope infrastructure package.

**Status:** Enabled by default.

### Why this exists

Persistence models are technical details owned by a business scope, while only the declarative foundation base is shared.

### Failing example

```python
class OrderModel(BaseSQLAlchemyModel):
    pass  # infrastructure/sqlalchemy/models/order.py
```

### Passing example

```python
class OrderModel(BaseSQLAlchemyModel):
    pass  # core/orders/infrastructure/sqlalchemy/models/order.py
```

### Detection notes

Follows exact path-qualified project inheritance from `BaseSQLAlchemyModel`. Statically abstract
project foundation classes are exempt, but an explicit table mapping remains concrete and fails
outside scope infrastructure even when its class name starts with `Base`.
