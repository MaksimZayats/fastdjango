## `tests.core-behavior-resolves-from-container`

Require mirrored core-behavior tests to resolve every concrete target from DIWire.

**Status:** Enabled by default.

### Why this exists

Resolving each concrete behavior proves its constructor graph is registered without prescribing test counts or assertions.

### Failing example

```python
def test_total() -> None:
    service = PriceService()
```

### Passing example

```python
def test_total(container: Container) -> None:
    service = container.resolve(PriceService)
```

### Detection notes

Checks each required mirrored unit module for a `test_` function using the native `container`
fixture from `tests/unit/conftest.py` and an explicit resolve call in that test's executable body for
every exact path-qualified concrete target. Parametrized, defaulted, and module-local `container`
shadows do not count, nor do calls hidden in nested scopes. Classes that retain inherited abstract
methods are not resolution targets.
