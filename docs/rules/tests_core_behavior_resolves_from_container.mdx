## `tests.core-behavior-resolves-from-container`

Require mirrored core-behavior tests to resolve every concrete target from DIWire.

**Status:** Enabled by default.

### Why this exists

Resolving each concrete behavior proves its constructor graph is registered without prescribing test counts or assertions.

### Failing example

```python
def test_total() -> None:
    service = PriceService()
```

### Passing example

```python
def test_total(container: Container) -> None:
    service = container.resolve(PriceService)
```

### Detection notes

Checks each required mirrored unit module for a `test_` function using the native `container`
fixture returned directly from project `get_container()` in `tests/unit/conftest.py`, with no nearer
fixture override or parameter reassignment. Every exact path-qualified concrete target needs a call
in the executable test body; dead branches, nested scopes, parametrized/defaulted shadows, and
un-awaited `aresolve` calls do not count. Classes that retain inherited abstract methods are not
resolution targets.
