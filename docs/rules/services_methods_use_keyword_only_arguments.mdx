## `services.methods-use-keyword-only-arguments`

Require public service methods to expose explicit keyword-only arguments after self.

**Status:** Enabled by default.

### Why this exists

Keyword-only service APIs make orchestration readable and prevent argument-order mistakes as contracts evolve.

### Failing example

```python
class PriceService(BasePureService):
    def total(self, price: int, quantity: int) -> int:
        return price * quantity
```

### Passing example

```python
class PriceService(BasePureService):
    def total(self, *, price: int, quantity: int) -> int:
        return price * quantity
```

### Detection notes

Checks effective public methods on direct and inherited project pure, read, and effect service
subclasses. Both ordinary positional parameters and `*args` violate the keyword-only contract.
