## `sqlalchemy.models-require-alembic`

Require Alembic configuration, revisions, commands, and tests for concrete models.

**Status:** Enabled by default.

### Why this exists

A concrete relational model changes the database contract and must be represented by reviewable, testable migrations.

### Failing example

```python
class OrderModel(BaseSQLAlchemyModel):
    pass  # no Alembic revision or migration test
```

### Passing example

```python
class OrderModel(BaseSQLAlchemyModel):
    pass  # Alembic config, revision, Make commands, and integration test exist
```

### Detection notes

When a concrete model exists, parses Alembic configuration and Python modules for real configuration
calls, migration functions, revision identifiers, and an upgrade-and-drift integration test. It also
requires executable `migrate`, `makemigrations`, and `migration-check` recipes that invoke Alembic;
comment-only placeholders do not count. Statically abstract or `Base...` declarative foundation
classes do not activate the rule.
